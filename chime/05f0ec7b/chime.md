It seems to me that we are unable to observe reality if we are not able to represent the observed internally?

1) Consider an imagined "white noise" system where nothing exist?

> *So the main idea here is to "Mind the Model" that seems to always be required for any representation of anything to be possible. Sometimes we call this a "pattern" but I want to argue it is deeper that that. For a pattern to be observable it must be possible for us to represent the pattern internally using a model in which we can instantiate this representation.*

> *Can we imagine something that has the characteristic of random noise? A system where there are no discernible particles nor energies or fields that forms any pattern or boundaries? Well that is hard. What is it that is random in that case. But let's take a step back and follow our intuition that there can be a system where any representation of the system just shows white noise. Nothing repeats. Nothing statys solid. No patterns repeats or remains. Everything we try to observe in this system just manifest into quantities with values that evolve totally random. Nothing seems to cause anything else. Or if it does it is totally unpredictable. This system then has the characteristic that there is no way for a part of this system to "be about" the other parts? Any way of trying to "be about" this system is just the system itself with all its randomness preserved.*

> *In this imagined system of no order nor structure in form or in evolution though time I argue nothin exists. This is a candidate for a system in which existence is impossible. Not only does matter nor energy exists. Time does not exist as passage of time can't be measured in a system where one point in time looks just as random as any other point. In this system abstract concepts does also not exist. Platons ideal meta-realm does not exist as in Platons definition reality is an instance of the ideal meta-realm. In this system numbers does not exist.*

2) Consider for Numbers to exists in reality we need to be able to have one part of reality be able to "be about" (model and represent), observe, some other (external) part of reality?

> *My claim is for numbers to be an abstraction that exists in reality we need one part of reality to be able to "be about" (model and represent) some other (external) part of reality. That is, a Number is a representation of something defined by the model we have instantiated as this representation. A number is defined in the model. A number "is about" something as defined by the model. Until reality somehow has become divided into one part that "is about" (models, observes and represents) some other (external) part of reality, until then Numbers does not exists. Because **Numbers exist in the model** used to represent the observed by the part of reality that "is about" the other part!*

3) Consider "Life" is any part of reality that is able to "be about" some other part of reality?

> *Could it be that the thing we model as "Alive" is always a part of reality that is capable to "be about" some other (external) part of reality?*

> *Now the obvious objection to this notion is to bring up computers and robots. Are they not "about" some other part of reality. Well, let's investigate. A robot runs a processing computer program that can use sensors to get information about reality and use this to compute actions in space and time. Is this to "be about" reality or is it just a deterministic ping-pong game between the internal processing of the robots computer program and the external world? It seems to mer we can argue that the processing made by the robot is in fact just an extension of the ability by the programmers of the robot to extend their own ability to "be about" reality. The programmers has represented reality and how to interact with that they already have in their own representation of said reality. The Robot just deterministically interacts with reality as defined by this representation of reality in the form of the computer program written by the programmer.*
