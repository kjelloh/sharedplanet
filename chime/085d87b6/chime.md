> *So the idea here is to imagine we create a programmable self organising complex system that we use to have a response emerge. So compared to a neural network where the input is processed into a categorisation output signal we instead uses a "network" that we feed with some signals and tries to make the network self organise input the input we are trying to "understand".*

> *Now first we let me state that I have no clue on how to make a "programmable" complex system so that when we excite it with some signals it will have a result emerge. But my intuition tells me it should be possible. It is at least imaginable to me that such a system can be designed.*

> *Secondly I try to imagine what kind of signals to feed into the emergence network to have the output emerge. I suppose we must (?) either feed it at least partly with the input we are aiming at reproducing. But I also think we can imagine a two step process where the input first is fed to a "normal" neural network to get a categorisation. Then we use the categorisation to generate a "hypothesis" signal set (that is a pre-identification of the pattern in the input) and feed the selected input signals to see if our emergence network will reproduce (predict) the input.*

> *At least intuitively we can now speculate that the "programming" or configuration of the emergence network now is our internal representation of what is "going on" based on the input signals we are seeing.*

> *So if this is how the brain works we can speculate like this. In the brain all sensory input is first fed through a neural network to categorise roughly what the input may be about. We can also imagine the input neural network is also set up expect certain types of inputs as given by the current circumstances. Like if I am at he Gym, at work or are reading a book in my bed. These circumstances would set up the input categorisation network to presume a limited set of "what is going on".*

> *Then we can imagine that our brain produces the appropriate signals to feed into the "sense making" emergence network. With the goal to have the original sensory input to emerge from being fed the input signals selected for the categorisation. Now the brain tunes the emergence network so that the sensory input emerges. And having been able to find the configuration that produces a matching emulation the brain now "experience" what the input is about. The emergence network "programming" IS the model of reality we can use to understand and interact with reality.*
