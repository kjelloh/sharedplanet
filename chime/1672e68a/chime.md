1) It seems I can delete all Index entry fields using word search-and-replace for "^d XE" (<https://answers.microsoft.com/en-us/msoffice/forum/all/how-to-remove-index-field-codes-in-word-2016/b04995b1-9d74-40b0-baae-01277d321cd2> )?

1. Press **Ctrl+H** to open the **Replace** dialog.
2. In the "Find what" box, type "**^d XE**" (without the quotation marks). This will cause Word to find and select the entire XE field.
3. Leave the "Replace with" box empty.
4. Click **Replace All**.



==&gt; THIS WAS A LIFE SAVER (I had a really contaminated word document with almost 2000 out-of-date index entries) :)
