Skriv om hur viktigt det är att respektera SD-väljare (eller vilken åsikt som helst). Baserat på att vi inte är rationella agenter utan drift-styrda, så måste vi inse att för att engagera sig i att skapa ett bra samhälle för alla, så måste vi argumentera med drifter. Om vi kan förstå känslorna under protektionistiska strömningar så kan vi också påverka dem och hitta den lösning som på-riktigt löser de problem våra hjärnor känner av.

Ett samhälle måste bygga på idéer som alla kan förstå och relatera till. Man skall inte behöva vara ”smart” för att känna att samhället fungerar och att vi som kollektiv gör rätt saker. I debatten förekommer en underliggande attityd att de som vill begränsa, skydda och utestänga till förmån för egna intressen och sammanhållning är ”mindre smarta” än de som vill hjälpa, öppna upp och samarbeta. Argumentationen fastnar i naiva som argumenterar mot inskränkta. Detta kan inte vara fruktsamt och ur ett lösningsperspektiv kan det aldrig leda framåt.

Bättre då att verkligen omfamna och förstå att de som föreslår handlingar som verkar egoistiska, ohjälpsamma och kanske till och med omänskliga inte behöver vara det. Det är bara agentens val att ta det säkra före det osäkra som får den konsekvensen. Som opponent behöver vi ifrågasätta även våra egna motiv och börja med att för oss själva säkerställa att de handlingar vi istället föreslår faktiskt är bättre för alla. Och sedan från denna ödmjukhet försöka hitta en tredje väg. Sedan behöver vi argumentera för denna tredje väg genom att adressera just de känslor som får våra opponenter att föreslå det vi anser vara förkastligt.

En väg att förstå SD är att inse att vi alla bär på förmågan att känna och agera som de gör. Vi är i grunden alla irrationella människor och vi kan alla känna rädsla för andra som inte beter sig som vi. Vi kan alla känna stolthet för vår egen grupp eller kultur. Vi kan alla mana oss till försvar av våra högre ideal. Vi kan alla avhumanisera de vi vill utesluta osv.

En startpunkt kan vara att hitta den känslo-bas som lockar SD-väljare. Det kan vara Stolthet för Sverige, våra rötter och vår kultur. Det kan avvara längtan efter trygghet och rättvisa. Det kan vara känslan av att vi gjort oss förtjänta av vår välfärd och att vi därför inte blåögt kan ge bort den till de som inte förtjänat den. Det kan vara rädslan att de som inte investerat blod, svett och tårar i detta land inte heller komne att värna detta land. Det kan vara känslan av att värna vår integritet. Att fortsätta värdera, vörda och känna tacksamhet till tidigare generationer som gjort detta samhälle möjligt för oss.

Allt detta kan vi alla förstå. Och kan vi förstå detta kan vi också bygga argumentation som manar till dessa känslor men som samtidigt öppnar upp Sverige för en framtid som faktiskt på riktigt möte den förändring som sker, en förändring vi inte kan isolera oss från. Och vi kan göra det på ett sätt som låter Sverige fortsätta vara ett land att vara stolt för. Ett land som fortsätter att modigt gå i bräschen bland världens länder när ingen annan vågar. Som vågar se sanningen, våga möta den och samtidigt bygger det trygga, stolta och rika samhälle vi alla längtar efter!
