A problem with Darwinet is how to validate that a node is a valid darwinet (secure) node. If no authorization is applied it would be very easy to create and distribute intruding nodes that behaves as real ones but that eavesdrop on domain activity!

Consider to authorize nodes using the same mechanism that bitcoin uses to validate each coin. To fake a Darwinet node would require a network with a CPU proser surpassing the network of authentic nodes. But then - how do we prevent fake nodes to be accepted in the firs place?
