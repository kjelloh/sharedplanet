I wonder if it is possible and convenient to operate a computer keyboard with both hands and feet as a church organist plays the organ with both hands and feet?

1) Consider a foot controlled keyboard to press modifier keys with the feet to have the hand free to only press single keys?

The basic idea here is to use ones feet that normally is not used for any input when working at a computer to press the modifier keys for a more convenient input of sequences like Shift-a ('A'), Cmd-V (Paste), Shift-Ctrl-Cmd-4 (macOS enter screen capture).

Now, it should be a "simple" task to build a prototype USB attached device that behaves as a secondary keyboard to try out different physical design of a foot controlled keyboard?

Modifier keys on personal computers[edit <https://en.wikipedia.org/w/index.php?title=Modifier_key&action=edit&section=2>]
The most common are:
⇧ Shift <https://en.wikipedia.org/wiki/Shift_key>
Ctrl <https://en.wikipedia.org/wiki/Control_key> (Control)
Alt <https://en.wikipedia.org/wiki/Alt_key> (Alternate) – also labelled ⌥ Option <https://en.wikipedia.org/wiki/Option_key> on Apple Macintosh keyboards
AltGr <https://en.wikipedia.org/wiki/AltGr_key> (Alternate Graphic)
◆ <https://en.wikipedia.org/wiki/Meta_key> – Meta key, found on MIT, Symbolics, and Sun Microsystems keyboards
⊞ Win <https://en.wikipedia.org/wiki/Windows_key> (Windows logo) – found on Windows keyboards
⌘ Command <https://en.wikipedia.org/wiki/Command_key> – Command key, found on Apple Macintosh keyboards. On older keyboards marked with the Apple logo.
Fn <https://en.wikipedia.org/wiki/Fn_key> (Function) – present on small-layout keyboard, usually on notebooks.
