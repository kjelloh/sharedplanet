			std::transform 		== map
			std::copy_if		== filter
			std::accumulate	== reduce

			==> But how can std::transform be the ”map” (In functional programming map returns a lifted function, not the actual execution of the lifted function)?

				==> std::transform creates a new output range by applying a function to each element in an input range

				Vector<T> —> Vector<U>
				                   F
						   ^
						   |
						map
						   |
				    		   f
					      T —> U				

				==> So yes, execution of std::transform(Vector<T>, Vector<U>,f) is kind of execution of F: Vector<T> —> Vector<U>, i.e. F(Vector<T>)
