4) Consider to decompose his talk into my hunch of layering Text processing into ”Semantics” (meaning), Script (Character Set), Encoding (representation)  and Storage (Code Units)?

	==> Could we argue that things like to_upper, to_lower, sort, search etc. belongs to the semantics /meaning) domain (we need to know what the characters we process actually mean)?
	==> Could we argue that Unicde, Iso-latin-1, ASCII belongs to the script domain (defines what characters to represent and how (what code points) to represent them)?
	==> Could we argue that UCS2, UTF-8, UTF-16 etc. belong to the encode domain (how we represent the code points in code units)?
	==> Could we argue that std::string, std::wstring, char[], char_t etc. belongs to the storage domain (what data structures used to represent the code units)?
