Ett sätt att beskriva vad pengar är är att säga att pengar är en kraft som bara funkar på människor.

1) Pengar får andra människor att göra saker för dig.
2) Pengar funkar bara på människor.
3) Pengar funkar bara på de människor som tror på de pengar du har. Man kan jämföra till exempel skillnader mellan bitcoin-pengar och dollar-pengar. Bitcoin pengar fungerar inte på alla medan vi kan förvänta oss att Dollar-pengar faktiskt fungerar på alla människor i hela världen.
4) Både pengar och Gud kan få andra att göra saker för dig. Men det finns pengar som funkar på alla människor medan det inte finns någon Gud som gör det.

Några fler egenskaper hos pengar.

a) Pengar går att spara och använda senare (Monetärt Kapital). De flesta andra saker som har ett värde fungerar inte så. Mat blir dålig, prylar blir omoderna och kunskap och färdigheter glöms bort.
b) Pengar kan lånas ut i utbyte mot mer pengar (lån)
c) Pengar kan bytas mot att någon gör något i framtiden (investering).
d) Egenskaprena a…c ovan kan kombineras till nya ekonomiska instrument (aktier, derivat, optioner)

Saker vi inte så ofta tänker på om pengar.

i) Pengar måste omvandlas till något annat för att få ett värde. Man kan köpa en resa eller en bil och då är det resan och bilen som är värdet. Pengar på banken kan ha ett litet värde i att skapa en tyget för framtiden. Men då bara om de i framtiden kan användas till något som har ett värde.
ii) Vi tänker sällan på vad vi skall använda pengarna till för att de skall skapa så höga värden som möjligt. Vi tar liksom för givet att det är pengarna is sig, och mycket pengar, som är det eftersträvansvärda. Men både i samhället och i privatlivet kan det vara väldigt stor skillnad på hur värdefullt det man använde pengarna till faktiskt är.
iii) Systemet att i princip allt vi värdesätter i livet måste gå via pengar skapar fenomen och sysslor som i sig har litet eller inget reellt värde. Reklam och jobb som inte känns meningsfulla är sådana exempel. Reklam behövs för att stimulera oss att omsätta pengar så att andra kan tjäna dom. Jobb utan mening uppstår när verksamheter antingen i sig självt producerar varor och tjänster var meningsfullhet är oklar eller när arbetet organiseras så kopplingen till det meningsfulla resultatet blir oklart.
iv) Beskattning av intäkter för att finansiera samhällets gemensamma tjänster skapar ett system där man bara kan bidra när man är någon som någon annan vill betala en för att få något gjort. Som kollektiv förlorar vi alltså när vi lyckas göra behovet av arbete mindre. Som samhälle kan vi inte tillåta det bekväma livet vi drömmer om som individer gå i uppfyllelse. Samhället förlorar då möjligheten att få människor att utföra samhällstjänster för andra. 
v) Företags incitament att minska kostnader och öka vinster skapar ett system där efterfrågan på arbete hela tiden minskar. Företagen förlorar på att tillgodose samhällets behov av många skattebetalare samtidigt som de tjänar på att tillgodose våra enskilda behov för att få det bekväma livet. Å andra sidan behöver företagen kunder som kan betala. Så företag som minskar sitt behov av arbetskraft är samtidigt beroende av att de får ett arbete någon annan stans. Företagen kan alltså inte tillgodose våra behov av bekvämare liv i form av mindre arbete.
vi) Vårt nuvarande system som bestämmer hur vi får pengar och vad vi kan göra med pengar kan alltså aldrig leda till det bekväma livet för mänskligheten. För att tillåta det bekväma livet behöver vi införa någon mekanism som gör det möjligt att minska mängden arbete samtidigt som vi fortfarande kan köpa det vi behöver för att leva rikt.
