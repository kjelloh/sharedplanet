2) Bitcoin provides monetary transactions using a currency that is not backed up by a bank (no ”Server”)

3) GitTorrent moves a Git Server to a Bittorrent network and uses Bitcoin blockchain to authenticate users (removing the GitHub server)

4) Darwinet may be seen as an initiative to move OpenID and Private Data to a P2P distributed network of services (making service-centric data into user-centric)?
