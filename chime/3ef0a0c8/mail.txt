The RAD Studio “import component” wizard seems like a good tool to easily create VCL components to use COM and Active X interfaced objects. But I never got the hang of where the generated files go, what gets installed and how to keep everything at one place to have it under proper version control.

1) The generated bpd-file always gets built to the global folder "C:\Users\Public\Documents\Embarcadero\Studio\15.0\BPL”

	==> And automatically installed packages refers to the bpd-file in this directory.
	==> This means these locally generated packages are NOT distributable to other machines and applications using components in such a package will fail (they are not available not installed on the other machine)

2) These steps seem to be one way of creating a project folder structure holding all files to build a package for one imported type library based component.

	==> Start by creating a project folder for the new project we are to create (the wizard we will use does not allow creation of new folders)



	==> In this case the new folder “MyImportComponentTestPackage1”

	==> Open RAD Studio and Ensure no current project is open.
	==> Select <Component> / <Import Component>



	==> In this case VCL for C++ and Next.



	==> In this case Import a Type Library and Next



	==> Search for the Type Library to import. In this Case UIAutomation. In this case select UIAutomationCoreRes and Next.




	==> Select “Generate Component Wrappers” (To enable created component to work in design time of the IDE)
	==> Define “Unit Dir Name” to be in the folder of the Project we are in the work of creating (i.e. press ellipsis (…) button and create the proper project folder)




	==> Select the Project folder we created above for the package project we are creating to build imported component - then OK and Next in the wizard.



	==> Select “Install to New Package” (To have RAD Studio create a new project for the package holding the imported component)



	==> Define the package name and folder by clicking the ellipsis (…) button and browse to our project folder created and used above



	==> In this case we named the package as the project folder (my own standard). Click <Save> and then wizard <Finish>.




	==> The wizard now detects the project we create needs VCL support. Click <Yes> to have it added.



	==> The wizard now saves generated project files. Note that the wizard suggests the correct project folder. Then accept with <Save>



	==> The wizard now builds and installs the package.

3) Seems that if we would like a version controlled project use installed VCL components produced by other version controlled package project we should put the bpl-file under version control and make the bpd-project part of the project group?
