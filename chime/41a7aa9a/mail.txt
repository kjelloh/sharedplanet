"FCPXML is a specialized format that uses XML elements to describe the data going between your app and Final Cut Pro. With FCPXML simplifying the data exchange, app users can:

	• Send large quantities of media from an asset management tool to be edited in Final Cut Pro. 
	• Send media clips—annotated with ratings, keywords, and metadata—and let Final Cut Pro organize the incoming media.
	• Receive rendered media and editing decisions for a project—including lists of media used—from Final Cut Pro for further processing, such as color grading and correction.

	• Record an audio/video stream and start editing the media in Final Cut Pro while the file is still being recorded."

5) Consider the FCPXML Format specification "About Final Cut Pro X XML 1.8" (https://developer.apple.com/library/archive/documentation/FinalCutProX/Reference/FinalCutProXXMLFormat/Introduction/Introduction.html#//apple_ref/doc/uid/TP40011227 <https://developer.apple.com/library/archive/documentation/FinalCutProX/Reference/FinalCutProXXMLFormat/Introduction/Introduction.html#//apple_ref/doc/uid/TP40011227> )?


"An FCPXML document represents one of the following Final Cut Pro X objects:

	• A single library.
	• A set of events.
	• A set of clips, which may contain keywords or smart collections."

The root top-level container element is <fcpxml>. The root element contains the following:
An optional <import-options> element. See Import Options <https://developer.apple.com/library/archive/documentation/FinalCutProX/Reference/FinalCutProXXMLFormat/EventsandProjects/EventsandProjects.html#//apple_ref/doc/uid/TP40011227-CH12-SW8>.
A <resources> element. See Resources <https://developer.apple.com/library/archive/documentation/FinalCutProX/Reference/FinalCutProXXMLFormat/Resources/Resources.html#//apple_ref/doc/uid/TP40011227-CH16-SW1>.
One of the following:
A <library> element. A <library> element contains a list of <event> elements (see Table 1-1 <https://developer.apple.com/library/archive/documentation/FinalCutProX/Reference/FinalCutProXXMLFormat/EventsandProjects/EventsandProjects.html#//apple_ref/doc/uid/TP40011227-CH12-SW11>).
 <>Note: As of FCPXML 1.4, an FCPXML document is self-contained and allows multiple events, but does not allow references to objects in another library.
Or, a series of <event> elements. An <event> element contains story elements and <project> elements discussed in the following bullet (see Table 1-1 <https://developer.apple.com/library/archive/documentation/FinalCutProX/Reference/FinalCutProXXMLFormat/EventsandProjects/EventsandProjects.html#//apple_ref/doc/uid/TP40011227-CH12-SW11>).
Or, a combination of story elements and <project> elements:
Story elements: <clip>, <audition>, <mc-clip>, <ref-clip>, <sync-clip>, or <asset-clip>. See Story Elements <https://developer.apple.com/library/archive/documentation/FinalCutProX/Reference/FinalCutProXXMLFormat/StoryElements/StoryElements.html#//apple_ref/doc/uid/TP40011227-CH13-SW1>.
A <project> element representing a timeline in a Final Cut Pro X project. A <project> element contains a <sequence> element (see Table 1-1 <https://developer.apple.com/library/archive/documentation/FinalCutProX/Reference/FinalCutProXXMLFormat/EventsandProjects/EventsandProjects.html#//apple_ref/doc/uid/TP40011227-CH12-SW11> and Table 2-1 <https://developer.apple.com/library/archive/documentation/FinalCutProX/Reference/FinalCutProXXMLFormat/StoryElements/StoryElements.html#//apple_ref/doc/uid/TP40011227-CH13-SW5>).
 <>Note: As of FCPXML 1.4, the <project> element now only defines a project timeline; events are now represented by an <event> element.
Collection elements: <smart-collection>, <keyword-collection>, or <collection-folder>. See Collections <https://developer.apple.com/library/archive/documentation/FinalCutProX/Reference/FinalCutProXXMLFormat/EventsandProjects/EventsandProjects.html#//apple_ref/doc/uid/TP40011227-CH12-SW7>.
