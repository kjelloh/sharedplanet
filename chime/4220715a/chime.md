Today anyone may apply for a library card at any library but libraries are unable to provide a single library card that gives access to all libraries. Thus each library implements theirs own IT-system, administration and library card system (user register).

1) This is an example of us citizens becoming “service schizophrenics” (we are viewed as different persons by each service)?  
2) It is inconvenient from a user point of view having to administrate several library cards (and access information) for several libraries (services)  
3) It is inefficient from a society point of view having each library district implement and maintain their own administration.  
4) Consider to design a Darwinet library app that enables swedish libraries to register users using their single Darwinet identity?  
5) The Darwinet app may also help to integrate existing web-servies for each library, creating a single-user experience?  
…

Consider to elaborate on this idea of using a Darwinet Domain to integrate existing library web-services (and backend systems?) into one?
