	Q: What is http "query"?

	A: It seems an http query string is the part of the url following a question mark containing name=value terms (https://en.wikipedia.org/wiki/Query_string )?

Typical URL containing a query string is as follows:
http://example.com/over/there?name=ferret
When a server receives a request for such a page, it may run a program, passing the query string, which in this case is, name=ferretunchanged, to the program. The question mark is used as a separator, and is not part of the query string.[2] <https://en.wikipedia.org/wiki/Query_string#cite_note-2>[3] <https://en.wikipedia.org/wiki/Query_string#cite_note-3>
Web frameworks <https://en.wikipedia.org/wiki/Web_Framework> may provide methods for parsing multiple parameters in the query string, separated by some delimiter.[4] <https://en.wikipedia.org/wiki/Query_string#cite_note-w3c-recom-4> In the example URL below, multiple query parameters are separated by the ampersand <https://en.wikipedia.org/wiki/Ampersand>, "&":
http://example.com/path/to/page?name=ferret&color=purple
The order of the queries doesn't matter (name=ferret&color=purple and color=purple&name=ferret both produce the same results) and the exact structure of the query string is not standardized. Methods used to parse the query string may differ between websites.
A link in a web page may have a URL that contains a query string. HTML <https://en.wikipedia.org/wiki/HTML> defines three ways a user agent can generate the query string:
an HTML form <https://en.wikipedia.org/wiki/Form_(HTML)> via the <form>...</form> element
a server-side image map <https://en.wikipedia.org/wiki/Image_map#Server-side> via the ismap attribute on the <img> element with a <img ismap> construction
an indexed search via the now deprecated <isindex> element

	A: According to elm documentation the query string is appended with a '?' to the url (https://package.elm-lang.org/packages/elm/url/latest )?
