	==> It seems each possible argument name should be a Pair of a name and a SUM of its possible values?

	==> It seems the whole argument list should be a meta-Product of interdependent argument name-value pairs?

	==> Consider we need value-dependent meta-values (types) to handle restrictions on what combinations of arguments that are actually allowed?

	==> Consider a way to infer a GUI with, let say, columns of argument options (so the user may choose the argument line of choice)?

	...
