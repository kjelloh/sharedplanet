Just a hunch but it seems to me we can make an argument that all math is in fact "just" different fancy ways of enumerating things?

1) Consider enumeration is an abstract way of naming different instances of "things"?

==&gt; Consider the relation between enumeration and counting?

> *Let say you have several apples on the ground. And your friend also has a bunch of apples. And now, for some reason, you would like to talk about each apple in some specific way. You could begon by giving each apple a name, say Adam, Eva, Gustaf and so on. Then you would be able to represent each apple in language and say things like - I think Gustaf is not rape, or - Adam is a Granny Smith.*

> *But some time in history a clever human realised this naming problem could be generalised into enumeration. So that each time we had several "things" we could use a general naming scheme. And enumeration was invented. This is apple number one, this is apple number two and so on.*

> *Now we realise that no matter in what order we enumerate the apples, the last apple will get the same name, the last number assigned. And we have counting. So counting is just the generalised process of enumeration where we do not care about what number each objects get. We just care about what number we assigned to the last object. The generalisation here is that we realise that the order we enumerate the things in does not matter. The last enumerated thing will always get the same number and we say we have a specific count of things.*
