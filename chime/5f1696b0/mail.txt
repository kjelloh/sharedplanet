From a video by Andreas Spiess I got to know about PlatformIO plugin for VScode and got the impression I would like to use it as better alternative for micro controller development than the Arduino IDE?


1) The Andreas Spiess youtube video “PlatformIO for Arduino, ESP8266, and ESP32 Tutorial” seems to live here (https://www.youtube.com/watch?v=0poh_2rBq7E <https://www.youtube.com/watch?v=0poh_2rBq7E> )?

	 

2) Consider the PlatformIO plugin for VSCode (https://docs.platformio.org/en/latest/ide/vscode.html#ide-vscode <https://docs.platformio.org/en/latest/ide/vscode.html#ide-vscode> )?

	==> It seems one can install PlatformIO plugin directly as “platform-ide” from within the VSCode Package Manager (https://docs.platformio.org/en/latest/ide/vscode.html#installation <https://docs.platformio.org/en/latest/ide/vscode.html#installation>)?

Download <https://code.visualstudio.com/> and install official Microsoft Visual Studio Code. PlatformIO IDE is built on top of it
Open VSCode Package Manager
Search for official platformio-ide extension <https://marketplace.visualstudio.com/items?itemName=platformio.platformio-ide>
Install PlatformIO IDE.

 
3) The PlatformIO open source initiative seems to live here (https://platformio.org <https://platformio.org/> )?
