Could we imagine a 3D-CAD tool that actually “knows” about standard house building concepts and restricts (helps) the user to construct house within these contains?

1) House construction could then become much easier by enabling the user to just “draw” and the tool will automatically “construct” the part using defined concepts?

	==> Consider being able to define a wall and the tool automatically constructs panel, wood-framework, isolation, inner wall and all mounting material (screens, nails etc)?
	==> Consider being able to define location of an electrical outlet, end the tool automatically routes and constructs wiring to that outlet?
	==> Consider being able to define location of a water tap, end the tool automatically routes and constructs piping to that water tap?

2) Consider being able to import and use existing pre-constructed parts of house building (e.g. windows, doors)?

	==> Consider the user to define using a specific window in a wall, and drawing that wall then places the window correctly in the constructed wall?
	==> Consider the user to define using a specific cupboard in a kitchen and the tool automatically places it according to standard and constructs mounting to the wall?
	
…

Consider to delve into this idea of a “construction aware” 3D-CAD tool that enables the user to just define the spatial properties of a building and the tool constructs the rest based on defined constraints?
