Since you now have the latest LLVM packages available from http://apt.llvm.org <http://apt.llvm.org/> you can install the latest libc++. First determine the latest version:

apt search libc++ | grep libc++

Then:

sudo apt install libc++-13-dev libc++abi-13-dev
