By designing each Darwinet node so that it may message with other nodes through the same IMAP account configuration and setup of Darwinet domains may be more flexible.

1) Each message must have a header identifying the target node.
2) Each node must fetch and delete only messages targeted for them.
3) Deletion may be done to a Deleted-message folder. The IMAP account may then allow inspection of messaging history which may be of interest for domain security reasons (spot malware activity)?
