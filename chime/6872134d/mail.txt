2) To use Boost library in Visual Studio C++ project it seems we need to define Additional Include file path AND link to correct 32-bit/64-bit Boost binary (library)?

	==> 1) To compile using boost headers - set the Project Property <C/C++>/<General> “Additional Include Directories” to “C:\local\boost_1_61_0” (The root folder of the installed Boost package)

	 

	==> 2.a) To link with 32-bit Boost 1.61 binaries - Set the Project Properties <Linker>/<General> “Additional Library Directories” to “C:\local\boost_1_61_0\lib32-msvc-14.0” (the 64-bit binaries folder of the installed boost package)



	==> 2.b) To link with 64-bit Boost 1.61 binaries (NOT for windows 32-bit console apps) - Set the Project Properties <Linker>/<General> “Additional Library Directories” to “C:\local\boost_1_61_0\lib64-msvc-14.0” (the 64-bit binaries folder of the installed boost package)



		==> Note: Failure to define for Visual Studio how to link will result in a link error (not finding the Boost library required)
