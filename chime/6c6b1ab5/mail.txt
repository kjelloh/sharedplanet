
1) Consider this github gist "Setting $PATH for zsh on macOS" ()https://gist.github.com/Linerre/f11ad4a6a934dcf01ee8415c9457e7b2 <https://gist.github.com/Linerre/f11ad4a6a934dcf01ee8415c9457e7b2> )?

	==> It seems the bottom line is that if we append to PATH in ~/.zprofile it will mutate the PATH variable after the tool path_helper is called?

"Using zsh, on macOS, avoid ~/.zshenv and choose ~/.zshrc or ~/.zprofile"

	
	==> The gist seems to propose the following order for how macOS using Zsh mutats the PATH to its final conetnt?

"For zsh <https://github.com/rbenv/rbenv/wiki/Unix-shell-initialization#zsh>, the order is like this:
/etc/zshenv (no longer exists on macOS by default)
~/.zshenv
login mode:
/etc/zprofile (calling path_helper)
~/.zprofile
interactive: /etc/zshrc ~/.zshrc
login mode: /etc/zlogin ~/.zlogin"
	NOTE: This should mean that if I do NOT care if my added path is reordered by path_helper I can also do the PATH mutation in ~/.zshenv?

2) It seems I can use pwd to append to ~/.zprofile and then edit the file to have the generated path added to PATH using the export statement?

	=>= In this example I add my own app "nudge" in a development directory to my Path for daily use :)

kjell-olovhogdal@Kjell-Olovs-Mac-Pro nudge % pwd >> ~/.zprofile
kjell-olovhogdal@Kjell-Olovs-Mac-Pro nudge % vi ~/.zprofile    
kjell-olovhogdal@Kjell-Olovs-Mac-Pro nudge % cat ~/.zprofile

export PATH=$PATH:/Users/kjell-olovhogdal/Documents/Github/nudge

kjell-olovhogdal@Kjell-Olovs-Mac-Pro nudge %
