It seems like it would be a good idea to separate the actual mobile network connection from the user interface devices we use and carry around?

1) The mobile network connection is what you access through a SIM-card and what you pay for to a mobile service provider.  
2) The user interface and application engine is your relationship with the platform provider (the ecosystem) and not with the mobile network provider.  
3) So, why not make the mobile network access into a ”puck” carrying the SIM-card and network connection?  
4) And have user interface devices tether with the puck?  
5) The ”puck” may then be used also at home (no need to have a separate cable internet connection at home)?  
6) The application-device (smartphone, tablet, lap-top, even IoT) can then get more powerful when they dop not have to carry power and electronics to implement the carrier interface?
