1) It seems the Jamulus project lives here on SourceForge (http://llcon.sourceforge.net <http://llcon.sourceforge.net/> )?

	==> It seems Jamulus interfaces the audio hardware using ASIO on WIndows, Core Audio on Mac and Jack on Linus?

"Jamulus is Open Source software (GPL, GNU General Public License) and runs under Windows (ASIO), MacOS (Core Audio) and Linux (Jack). It is based on the Qt framework and uses the OPUS audio codec."


	==> It seems Jamulus uses the QT Framework for the frontend, the OPUS interactive audio codec for streaming and some old Stanford C++ code for reverberation?

This code contains open source code from different sources. The developer(s) want to thank the developer of this code for making their efforts available under open source:

Qt cross-platform application framework: http://www.qt.io <http://www.qt.io/>
Opus Interactive Audio Codec: http://www.opus-codec.org <http://www.opus-codec.org/>
Audio reverberation code: by Perry R. Cook and Gary P. Scavone, 1995 - 2004 (taken from "The Synthesis ToolKit in C++ (STK)"): http://ccrma.stanford.edu/software/stk <http://ccrma.stanford.edu/software/stk>
	==> It seems Jamulus "Rule Number One" is to NOT LISTEN TO YOURSELF, only to the feed from te others (https://github.com/corrados/jamulus/wiki/Software-Manual <https://github.com/corrados/jamulus/wiki/Software-Manual> )?



"
Rule Number One!

DO. NOT. LISTEN. TO. YOUR. DIRECT. SIGNAL!

This is obviously hard for singers and some acoustic musicians, but even if your connection is good, if players aren't listening to their own signal coming back from the server, your synchronisation willsuffer.
"
