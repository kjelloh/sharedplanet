1) Found information on boost web-site about ready-to-install files for windows (http://sourceforge.net/projects/boost/files/boost-binaries/1.59.0/ <http://sourceforge.net/projects/boost/files/boost-binaries/1.59.0/>)

	==> A dependcy text file stated that for Visual studio 2015 i was to install the file post-fixed msvs-14 (http://sourceforge.net/projects/boost/files/boost-binaries/1.59.0/DEPENDENCY_VERSIONS.txt/download <http://sourceforge.net/projects/boost/files/boost-binaries/1.59.0/DEPENDENCY_VERSIONS.txt/download>)

2) I downloaded and ran  the file boost_1_59_0-msvc-14.0-64.exe (http://sourceforge.net/projects/boost/files/boost-binaries/1.59.0/boost_1_59_0-msvc-14.0-64.exe/download)

3) The boost library 1.59 was installed by default to "C:\local\boost_1_59_0”

4) This was the lead I followed to install and configure for Visual Studio (http://stackoverflow.com/questions/2629421/how-to-use-boost-in-visual-studio-2010)
