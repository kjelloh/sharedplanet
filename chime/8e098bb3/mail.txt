It seems at this stage of thinking that the core item of the Meta Value Model is the Identifier binding a name to a meta-value and storing an optional value?

1) Consider the Identifier contents and its relation to Declaration and definition?

	==> Consider the Identifier stores a meta-value reference and a value instance?

	MetaValueIdentifier {
		Name name;
		MetaMetaValueReference meta_meta_value;
		MetaValue value;
	}

	==> Consider to use the term ”Value” to mean the Values of the meta-layer where the Identifier lives?

	ValueIdentifier {
		Name name;
		MetaValueReference meta_value_ref;
		Value value;
	}

2) Consider a Declaration and Definition is operations relating to an Identifier (not objects themselves)?

	==> Consider a Declaration brings an Identifier into existence (by binding a value name to a meta-value reference)

		number1 : number

		Corresponds to…

		miv[”number”] = new Identifier(”number1”, &miv[”meta/number”])

	==> Consider a Definition binds an Identifier to a Value instance?

		number1 = 4

		Corresponds to…

		miv[”number”]->value = 4;
