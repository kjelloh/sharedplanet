It seems it could prove valuable and a good idea to investigate hos a Meta-Stack organised User Interface would look like?

1) Consider a Film Edit (e.g., iMovie, KDenlive, Final Cut Pro) user interface organised into Meta Stack Layers?

	

	==> Consider Meta-1 layer is the actual “stuff” (data) we are morphing?
	==> Consider Meta-2 may be used to model “Types” of data (e.g., Video, Audio, Image…)?
	==> Consider Meta-3 may be used to model “Composition” both in space (e.g., picture-in-picture) and in time (sequence of cuts and transitions)?

2) Consider how we can use the Meta-model to model environment changes (e-g-, tool changes like cursor select, hand, blade…)

	==> It would seem changes in select too is in fact a change of the cursor type (select, hand, blade…)
	==> Consider workspace view changes are Meta-3 Composition changes (The view is a meta-2 type and the view change is a meta-3 view-kind change)?

3) Consider how Meta-3 as Sum, Product compositions may manifest as User Interface components?

	==> Consider picture-in-picture is a Product-composition indexed by lane-names (lanes compose as stacked frame elements)?
	==> Consider if we can imagine SUM-compositions in space or time?

		==> A SUM composition in space would be a set of alternative elements at some location in space (indexed by what?)
		==> A SUM composition in time would be a set of alternative elements at some location in time (indexed by what?)

4) Consider how a film edit user interface actually models the meta layer model both in space (layers) and time (lanes)?

	==> It seems we here have a good example of how a Meta Stack Model may manifest in both space and time?
