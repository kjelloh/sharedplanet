A lot of the open source libraries I tried out (boost, CMake, Clang, Coco) provide build instructions for Visual Studio but not for RAD Studio (neither Borland C++ BCC32 nor Clang compilers BCC32C and BCC64).

1) Consider to understand to what degree *.lib files are linkable from RAD Studio projects?

	==> At least Visual Studio *.lib files are generated for 32-bit targets.
	==> RAD Studio expects 64-bit libraries to be in *.a format (ELF64 format)

2) RAD Studio defines different CLang versions for XE7 and Seattle

	==> Seattle seem to be based on Clang 3.3 (http://docwiki.embarcadero.com/RADStudio/Seattle/en/BCC64)?
	==> XE7 seem to be based on Clang 3.1 (http://docwiki.embarcadero.com/RADStudio/XE7/en/BCC64.EXE,_the_C%2B%2B_64-bit_Windows_Compiler)?
