Consider it could be a good idea to document how to and the result of installing the Qt development environment on different platforms?

1) Consider to document how I installed Qt on my MAC OS (Macbook Pro 2014)

	==> The selection between purchased and free version seems to be provided here (https://info.qt.io/download-qt-for-application-development <https://info.qt.io/download-qt-for-application-development>)
	==> I downloaded the Open Source Installer from the Qt web-site (https://www.qt.io/download-open-source/?hsCtaTracking=f977210e-de67-475f-a32b-65cec207fd03%7Cd62710cd-e1db-46aa-8d4d-2f1c1ffdacea <https://www.qt.io/download-open-source/?hsCtaTracking=f977210e-de67-475f-a32b-65cec207fd03|d62710cd-e1db-46aa-8d4d-2f1c1ffdacea>)

	==> I ran the installer and had to create a Qt account (See separate documentation)

	==> The installer stated it would install to “/Users/kjell-olovhogdahl/Qt”
	==> I selected to install lastest versio 5.9.1.

		==> The size was stated to 21 Gb.

	==> The download and start of Qt creators seems to work alright :)

2) Consider to document how I installed Qt on my Linux Mate (Ubuntu 16.04) machine?

	==> I selected to download the open source version of Qt from this page (https://info.qt.io/download-qt-for-application-development <https://info.qt.io/download-qt-for-application-development>)

	==> Firefox Web browser (or was it linux itself) offered to open the qt-unified-linux… .run with “Atril Document Viewer” (which I did not)
	==> I selected to download the *.run fil as a file.

	==> Then I had to change the file to be executable (as all linux users know and love to do…*sigh*) (https://askubuntu.com/questions/236811/how-do-i-install-qt5-which-comes-as-a-run-file <https://askubuntu.com/questions/236811/how-do-i-install-qt5-which-comes-as-a-run-file>)
