> *So the basic idea here is to try and see what Gödel's Incompleteness Theorem is actually implying about our ability to determine how reality will develop even in a deterministic universe. If we by "Deterministic" mean "computable" using the formal system of mathematics as defined by the model consisting of the physical laws, it should follow that Gödels Incompleteness Theorem must apply to this formal system. And if reality is in fact isomorphic to this formal system, then we can not prove that the current state of the universe is in fact a valid state reachable from the initial state at the big bang?*

> *Now, I assume it may still be possible to compute the current state of the universe if we just knew the initial state and had sufficient time and computational power. So it seems what Gödels Incompleteness Theorem prohibits us to to take a "short cut" and prove that the current state correlates with the initial state.*

> *Further, Gödels Incompleteness Theorem also tells us that any formal system to model reality must, to be consistent, be "incomplete" in that it must be based on unprovable axioms. Now, the interesting thing about this is how we, as living actors, are able to identify these axioms if we are also operating totally within the formal system of reality. Gödel's Theorem tells us the axiom must come from "the outside" of the system. How can we come up with these axioms for the formal system to model reality if we are within this system?*
