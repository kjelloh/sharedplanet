1) Consider a Constructor in C++ taking member values to use in construction?

	struct A {
	private:
		int m_x;
		bool m_b;
		string m_s;
	public:
		A(int x, bool b, string s);
	};

	==> Consider the Constructor is in fact a function taking three parameters (one for each member in the struct to construct)?
	==> Consider with Currying we can break down into composition of three functions, each building one member value into A?

	A a = builder<A>()

		.b(false)
		.s(”Wow”);

	==> Consider this also enables us to enforce a correct full build of A?

		==> It seems we require the client to build A by composing builder functions in the correct order (not leaving one out)?
