An SPC must be able to download the template for the ”Declaration of Dependence” and an SPB must in the same way get hold of the template for ”Declaration of Commitment”.

1) Wikipedia only allows upload of media files. The png-format is allowed so the png-template may be provided in this way (https://en.wikipedia.org/wiki/Help:Files)  
2) On Facebook ones seems to be able to upload files to groups (group documents). But groups seems to be restricted in number of members? (https://www.facebook.com/help/162866443847527/). Facebook pages seems to be designed for organisations and brands with unlimited number of followers but they do not provide file uploads?  
3) Twitter also seems to allow upload of media files. They support png-format (https://dev.twitter.com/rest/public/uploading-media). But there seems to be no way of actually storing any files for later download with the user account?  
4) DropBox allows urls to be created to public files for global download. Thus, by creating a free DropBox account we could expose SPB/SPC files for download using such a mechanism (https://www.dropbox.com/help/167?path=sharing_files_and_folders).  
4a) Dropbox free account has access limits (https://www.dropbox.com/help/4204). It states ”Dropbox Basic (free) accounts: • The total amount of traffic that all of your links and file requests together can generate without getting banned is 20 GB per day. • The total number of downloads that all of your links together can generate is 100,000 downloads per day."  
5) A DropBox account may be interfaced by different social media.  
5a) Facebook groups may share Dropbox files (https://www.dropbox.com/help/383). But for now the number of group members are restricted and Facebook Pages does not provide Drobox integration?  
6) Github provides free account with 1 GB traffic a month (https://github.com/pricing).  
7) Sourceforge (http://sourceforge.net) does not seem to provide any information about download limits (but of course there must be)?  
…

Seems the best we can do is encourage Shared Planet Citizens to share the SP-files on their own services (e.g. Dropbox ow web-pages) to minimize any traffic restrictions if this takes of?

a) Distributed file download may require the user must be able to check that the downloaded files are authentic? Consider to provide some easy to use mechanism to verify a hash-value or what have you?  
b) Distributed file download needs some form of network to organize where to find a good download. Consider to study how open source programs distribution has solved this?
