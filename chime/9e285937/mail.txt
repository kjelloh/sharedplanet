2) Consider to use their gitbook on embedded C++ programming for leads to embedded darwinet library (https://arobenko.gitbooks.io/bare_metal_cpp/content/ <https://arobenko.gitbooks.io/bare_metal_cpp/content/>)?

	==> Exclude Dynamic Memory Management (https://arobenko.gitbooks.io/bare_metal_cpp/content/compiler_output/dyn_mem.html <https://arobenko.gitbooks.io/bare_metal_cpp/content/compiler_output/dyn_mem.html>)?
		==> Warning: Requires code that can handle nullptr return instead of std::bad_alloc throw (e.g. can inject problem into third party library code not designed for nullptr returns on new)
	==> Exclude Excpetion Handling (https://arobenko.gitbooks.io/bare_metal_cpp/content/compiler_output/exceptions.html <https://arobenko.gitbooks.io/bare_metal_cpp/content/compiler_output/exceptions.html>)
		==> Warning: May require implementation of residue __throw_xxx functions put in place by compiler (or libraries)
	==> Exclude RTTI (https://arobenko.gitbooks.io/bare_metal_cpp/content/compiler_output/rtti.html <https://arobenko.gitbooks.io/bare_metal_cpp/content/compiler_output/rtti.html>)
		==> Warning: typeid operator, dynamic_cast and overloading will not work.
		==> Q: Will boost::variant work as replacement (note no dynamic memory, exception handling and RTTI may render this impossible)?
	==> Exclude the standard library (https://arobenko.gitbooks.io/bare_metal_cpp/content/compiler_output/nostdlib.html <https://arobenko.gitbooks.io/bare_metal_cpp/content/compiler_output/nostdlib.html>)
		==> Warning: Requires explicit implementation of startup-code (e.g. initialisation and call of main-function that normally is provided by C++ runtime)
	==> Exclude static object destruction by mailing main an eternal loop (never return) (https://arobenko.gitbooks.io/bare_metal_cpp/content/compiler_output/static.html <https://arobenko.gitbooks.io/bare_metal_cpp/content/compiler_output/static.html>)
		==> Warning: static objects may require explicit implementation of compiler-generated "guard-acquire" and "guard-release” calls (thread safe static data).
