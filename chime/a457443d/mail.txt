So, I have re-created a fresh Ubuntu 14 Parallels machine on my MAC. Perhaps it would be a good idea to document for future use the operations I made to configure it to my taste?

1) I created the Ubuntu 14 machine using Parallels built in “new machine” wizard of Parallel Desktop Control Center (the upper-right-corner plus-sign)

	

	==> The machine was created from downloaded iso-image and created user “parallels” (as root)

2) I executed the Software updater until it showed “…however there is an upgrade to 15 available”.

	==> I ran the upgrade to version 15.

		==> It took 2-3 hours for the download part to finish (be patient)
	
	==> The upgrade actually seem to have failed (it hanged on restart and failed to reboot after being stopped)

		==> I decided finally to scrap this whole installation and start over from fresh.

	==> I decided to simply stick with 14 and upgrade when appropriate (14 seem to be the current “standard”)?

	...

3) I configured Ubuntu to use Swedish MAC keyboard.

	==> Clicked the cogs-wheel button in ubuntu main window upper right corner.
	==> Selected System Settings.
	==> In Dialog, selected “Text Entry”
	==> In dialog - pressed left pane “input sources to use” bottom button ‘+’
	==> In dialog - selected “Swedish (Macintosh)”
	==> Back in “Text Entry” Dialog - selected US Keyboard and pressed ‘-‘ (to remove)

	==> Now Ubuntu console window used Swedish Keyboard layout ok.

4) Installed Clang on Ubuntu MATE 16.04 machine

	==> In <System> / <Administration> launched “Software Boutique"




	==> In “Software Boutique” installed “Synaptic Package Manager” (success)

	==> Launched the Synaptic Package Manager and searched fro llvm.
	==> Checked all llvm 3.9 entries
	==> Clicked Apply
	==> A dialog opened showing download and install progress (success)



5) Installed Clang on Ubuntu Machine.

	==> Available downloads seem to be published here (http://llvm.org/releases/download.html <http://llvm.org/releases/download.html>)?

	==> LLVM seem to support the apt command (advanced packaging tool) of ubuntu on this page (http://llvm.org/apt/ <http://llvm.org/apt/>)?

		==> It seems we first has to enter “deb” entries to file “/etc/apt/sources.list” (https://gist.github.com/fyears/745da3cf6b19dbff3d0e <https://gist.github.com/fyears/745da3cf6b19dbff3d0e>)

[sudo] password for parallels: 

			==> This seem to open up and editor to enter lines into the /etc/apt/sources.list file?
			==> It seems the “<< LLVMAPT” defines how to end input (because entering the last LLVMAPT ends the input of line)?

				“'deb' is not a command. It is used in sources.list file to indicate a Debian software repository"
