> *So the basic idea here is that if we live in a simulation we can't expect to have any reliable information to form a model of the non-simulated reality!*

> *The idea is based on my observation and proposition that we do not know how we are able to "be about" that which is outside us. This is an extension of the older idea that we are restricted to what our senses feeds us to make up the state of reality. My argument is that we must also "mind the model" i.e., note that we need something to represent. The most simple example is our idea about numbers. For number to exist we must first have "things" to count. ANd for things to exist we need a model in which we can represent "things". Like, if we lived in an environment where our senses was fed only "white noise", then we would be unable to make a model of this white noise where there are any distinguishable things ate all.*

> *Anyhow, if we live in a simulation we would expect our ability to discover a model where a reality exists is restricted to the kind of reality we can suspect based on the reality we are fed by the simulation.*

> *Another way to say this is that in a simulation any information about the reality in which the simulation is run is totally out of reach to us!*
