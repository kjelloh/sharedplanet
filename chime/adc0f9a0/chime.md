==&gt; It seems we can suspect that a HD (1.44 MB) 3.5" floppy disk reader can read but not write 720 kB floppy disks as these floppy disks share the same 135 track-per-inch format?

> *From wikipedia and other sources I get the information that a 720 kB DD 3.5" floppy disk is an 80 track 500 kB per side disk and an 1.44 MB HD 3.5" floppy disk is an 80 track 1 MB per side floppy disk (See <https://en.wikipedia.org/wiki/List_of_floppy_disk_formats> ). This would then mean that they share the same 135 track-per-inch density and the difference is "only" that the DD uses a lower 8717 bit-per-inch record density while the HD can sport 17 434 bits-per-inch. From this we should be able to suspect that a HD floppy disk reader should be able to pick up the recorded bits on a DD disk.*

> *BUT - We should also suspect that a HD floppy disk driver may NOT be able to write reliably to a DD floppy disk. The magnetic substrate on the DD floppy disk is 2 µm magnetic iron oxide while on the HD disk it is 1.2 µm cobalt-doped iron oxide.*
