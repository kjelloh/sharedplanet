	==> They implement an interesting thread-safe lock-free Producer-Consumer queue (https://github.com/facebook/folly/blob/master/folly/docs/ProducerConsumerQueue.md)?

		==> Note that the queue aims in posting data, not functors (although it may of course do that to)

	folly::ProducerConsumerQueue<folly::fbstring> queue;

    std::thread reader([&queue] {
      for (;;) {
        folly::fbstring str;
        while (!queue.read(str)) {
          //spin until we get a value
          continue;
        }

        sink(str);
      }
    });

    // producer thread:
    for (;;) {
      folly::fbstring str = source();
      while (!queue.write(str)) {
        //spin until the queue has room
        continue;
      }
    }
