Could it be a good idea to have a Todo-scheduler that based on your current mood, location (in space and time) or commitments (e.g. time-scheduled tasks) provides a “Slot Machine” that suggests tasks to attend to?

-1) Consider a core-idea for this behaviour is to allow for faster task-switch?

==&gt; By making it fun to jump to a new task plus having each task “cache” the state where to “take off” (what to do next) the task-switching becomes fun, faster, and gets done more often (makes it more meaningful)?  
...

1) Consider a Slot Machine with three reels marked with Todo:s?

==&gt; Consider one reel for each category of Todo:s (mood, location, commitment)?  
==&gt; The first one (mood) aims to propose something the user would like to do (joy)  
==&gt; The second (location) aims to propose something the user should take the opportunity to do (possible)  
==&gt; The third (commitment) aims to propose something the user must do (while there is time)

==&gt; Or, Consider some random mode that places other Todo:s on the reels?

2) Consider to enable the user to spin over and over to get new suggestions?

3) Consider to have the user report attended tasks and in return “Win” (jack-pot like feeling)?

4) Consider some truth-web-like or geographical-map-like visualisation of “work done”?

==&gt; Consider a game-board approach which markers moved along paths to visualise work done?  
==&gt; Consider the idea of using the “garden metaphor” where attention to tasks (work) results in plants growing higher or burst into flower?  
==&gt; A “replay” of recent work may be visualised as gardeners, birds, insects attending (visting) the plants?  
==&gt; Plants (Todo:s) that has not gotten attention for a while may turn in to cacti to live longer without attention?  
==&gt; Or they wither away?  
==&gt; Consider to postpone Todo:s on the future by visualise such tasks as Seeds (we can later plant them to start attending to them)?

5) Consider other “lotter like” or “spin wheel” interfaces to get Todo proposals?

6) Consider to input what type of Todo:s to “win” by some “betting” game interface (e.g. a roulette like spin wheel)?

==&gt; The user “bets” on Todo:s for a certain mood, location and commitment knowing the odds for each category?  
==&gt; The Odds for Commitment-based Todo:s goes down as the time when they must be attended to gets closer (e.g. reaching deadline or time-scheduled meeting)?  
==&gt; Consider that “betting” (for entering wishes) and learning odds (for knowing whats planned) is a fun way of interacting and attending to ones needs?
