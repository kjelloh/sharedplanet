3) Consider my comments on using the full featured Joyshare Media Cutter?

==&gt; The application should show the name of the opened file.

> *When moving though raw video files to cut down with Joyshare Media Cutter it is easy to get lost on what file is next to edit. And because Joyshare Media Cutter does NOT show the name of the current open file you get ni help there.*

> *When in doubt you can open the output director and see what the name is of files that has been exported (Joychare Media Cutter creates a folder with the name of the original raw video file).*

![](<Screenshot 2019-05-06 at 15.36.31.png>)

*The output directory uses original raw video file names for the export output folders (here MVI_1823 was the last file cut down)*

==&gt; You cant define a new start at a location after the last end defined

> When you add a new segment and tries to define it to start later than the first segment (which of course is precisely what you want to do), then you can't do that. You have to first define a new end for the new segment, then define the exact start and end.

![](<Screenshot 2019-05-06 at 15.40.40.png>)

*You can't set the start of an added segment after the end of the previous one*
