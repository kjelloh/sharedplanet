Twitter has implemented an API through which all the user tweet history may be downloaded. A Darwinet node that uses e-mail account messaging may thus be able to interface this feature quite ”easy” (http://www.adweek.com/socialtimes/twitter-archive/478017)

1) The interface is designed to be a user interface.  
2) The user requests an archive to be created for download using the web user interface to the account.  
3) The user receives and e-mail with an url to the account where the archive may be downloaded.  
4) The user browses to the url, logs-in and is presented with a download button.  
5) The user hits the download button and a zip-file will be downloaded to the users computer file system.

Consider to study how this feature may be automated by a Darwinet application?
