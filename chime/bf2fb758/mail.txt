		“MSYS2 provies a minimal shell required to run autotools and other build systems…"

	==> Cygwin seems to aim to bring the whole Linux shell to windows (https://cygwin.com/index.html <https://cygwin.com/index.html>)?

		“...a large collection of GNU and Open Source tools which provide functionality similar to a Linux distribution on Windows.”

	==> The DOS shell seem to be what is proivided by cmd.exe (https://technet.microsoft.com/en-us/library/bb490890.aspx <https://technet.microsoft.com/en-us/library/bb490890.aspx>)?

		“Command-line tools must be run at the prompt of the Cmd.exe command interpreter."

cd GSL

cmake --build . --config Debug
