2) Consider how we can imagine graphical work tool-chains and what operations that are actually involved?

==&gt; Consider Modelling and rendering are separate operations (the model can be manifested as different types of rendering depending on how the model is manifested)?

Model —&gt; (Render operation) —&gt; real-time Image or Video (for efficient real time view during work with model)

==&gt; Consider rendering is separate from Encoding (a rendering can be compressed into a file for persistent storage and operate viewing through the process of encoding)?

Real-time Image or Video —&gt; (Encoding operation) —&gt; Compressed Image or Video bit-stream (e.g., For persistent storage as file or real-time streaming to network)?

==&gt; Consider Encoding is a step after rendering to make sharing and storage of rendered images or videos more efficient?

==&gt; Consider CAD is separate from CAM in that CAM is a process to manifest a model into an actual physical object?

CAD —&gt; (Additive or subtractive manufacture process) —&gt; CAM

==&gt; Consider how we can separate the design Model from the manufacture Model?

Model of design —&gt; Model of Manufacturing

3) Consider in what way we can imagine to use Tha-Modelling to get a grip of how graphical work tool chain operations relate to each other?

==&gt; Consider a 3D Model of a design is Meta to a CAM model of manufacturing (CAD is the constructor for CAM)?

n+1:  CAD  
n:  CAM

==&gt; Consider a 3D model is Meta to a rendering (The 3D Model is the constructor of a rendering?

n+1: 3D Model  
n: Rendering

==&gt; Consider physical modelling is interaction on a physically manifested 3D design (The physical modelling is in the "same" reality-level as the manifested model)?

n+1: 3D Model  n+1: Model of Physical Environment  
n: Physical Model n: Physical Environment

==&gt; Consider the Model of a physical environment is the constructor for the Physical Environment (that is to exist and interact in the "same" reality as the manifested 3D Model of the object to simulate)?

4) Consider for transformation from a model to a persistent compressed storage we would like to have the operation to be made very close (in line with) the actual writing to the SSD?

==&gt; Consider an SSD with an additional FPGA that we can configure for e.g. H.264 encoding on a rendered bit-stream (truning the rendered graphics into compressed graphics)?

==&gt; Consider what options we have to actually use run-time software to trun software defined operations into FPGA implemented hardware accelerated operations?
