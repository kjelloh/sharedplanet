	==> It seems in C++ 11 one added the possibility to define “reference qualifiers”?

	==> It seems the “ref-qualifiers for member functions” defines the nature of the reference to the called object (that is, if the caller calls the object referenced by value, by reference or by rvalue reference)?

template <typename T>
class optional
{
  // ...
  T&       value() &; //1
  T&&      value() &&; //2
  T const& value() const&; //3
};

		…is equivalent to the free functions:

T &      value(optional<T> &      this_); //1
T &&     value(optional<T> &&     this_); //2
T const& value(optional<T> const& this_); //3

		==> Thus the compiler is able to dispatch the call at compile time depending on the “nature” of the called object?

		//1 - This function will be dispatched when the caller calls a mutable lvalue object (object in a named variable)
		//2 - This function will be called when the caller calls on a mutable temporary rvalue object (anonymously created object)
		//3 - This function will be dispatched when the caller calls on a const lvalue object (object in  a named variable)
