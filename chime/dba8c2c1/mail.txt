Would it be possible to access the current C++17 draft documentation and parse it in some way that enables a Doc-to-help project to generate its output formats based on the source?

1) Consider to use the (TeX?) source on github (https://github.com/cplusplus/draft <https://github.com/cplusplus/draft>)?

	==> The output seems to be pdf?

”
To typeset the draft document, from the source directory:

	• run latexmk -pdf std

That's it! You should now have an std.pdf containing the typeset draft.
"

	==> On MAC they recommend MAC version of Tex (http://tug.org/mactex/ <http://tug.org/mactex/>)?

	==> The latexmk command line manual seems to live here (http://man.cx/latexmk <http://man.cx/latexmk>)?

		==> latexmk seems to be able to generate dvi, ps, pdf or ”hardcopy” formats?

”latexmk issues the appropriate sequence of commands to generate a .dvi, .ps, .pdf and/or hardcopy version of the document"

		==> The dvi-format seems to refer to the ”Device Independent Format” (https://en.wikipedia.org/wiki/Device_independent_file_format <https://en.wikipedia.org/wiki/Device_independent_file_format>)?
		==> The ps-format seems to refer to the ”Postscript” language (https://en.wikipedia.org/wiki/PostScript <https://en.wikipedia.org/wiki/PostScript>)?
		==> The pdf-format of course refers to Adobe pdf (https://en.wikipedia.org/wiki/Portable_Document_Format <https://en.wikipedia.org/wiki/Portable_Document_Format>)

	==> LaTeX seems to be the name of an open source (GNU LPPL) for Tex tools (https://www.latex-project.org/get/ <https://www.latex-project.org/get/>)?

	==> This seems to be a good approved list of TeX distributions and tools (http://www.tug.org/interest.html#free <http://www.tug.org/interest.html#free>)?
