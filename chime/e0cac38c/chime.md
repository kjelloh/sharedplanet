Capitalism defines capital as a gathering of already produced values that may be used to create new value (invested or consumed).

Money, as a media to exchange capital, fails to value other drives for human actions apart from the will to gather wealth to consume goods or services.

Could it be that we can define other currencies to value other drives human has?

1. Can we try and design a neutral currency for happiness?
2. Could ”value to society” be expressed in its own currency?
3. Maybe knowledge can be expressed in some form of currency?

Money, as a neutral value that may be used to make others ”work” does not cover these other forms of values we as humans experience. We call these values as invaluable. Things like love, pleasure of beautiful art, serenity of nature or life and so on.

Consider to try and apply special currencies to value these things and go on to think if such values may then be exchanged? Also, if these currencies can exist, then what can we trade them for? If money may be used to make some other work for you (return services or goods), then what may these other currencies be used for?
