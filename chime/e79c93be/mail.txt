5) Can reality be a "Penrose Tiling" and what would that "mean"?

So the basic idea here is if reality somehow is made up of pieces that tiles like Penrose Tiling but in three space (or four space-time?) dimensions. Now we seem to see actual repetition of patterns in reality. So much so that we can compute how matter will organise. But does that rule out the possibility that we just happen to live in some part of reality where these patterns exist locally although they do NOT repeat throughout the universe?

6) Consider the information content of a Penrose Tiling - is it infinite or is the pattern fully determined by the two tiles and the rules of placing the tiles?

Now this may potentially be linked to the concept of entropy and also the idea that "information can never be destroyed" that poses a problem with black holes leading to the proposition of reality being a hologram (the information swallowed by a black hole is stored in the event horizon of the hole).

The information required to describe an infinite Penrose Tiling would initially seem like it must be infinite as the pattern of the tiling never repeat. Thus it seems we need to report where each tile of the infinite tiling goes to reproduce it which thus would mean an infinite amount of information is required.

On the other hand, if we need only two tiles and the rules on how to place the tiles at least this initial information is finite? Would that mean that there could be a rule for what tile to select and where to put it all the way from the starting tile that would fully define a given Penrose Tiling? In that case the information of this infinite no periodic Penrose Tiling is in fact still finite. I find this possibility intriguing. It would mean a pattern that does NOT repeat is still generated by a generator defined by a finite algorithm? Is this not a contradiction?

Further, if there are infinite patterns generated by a finite algorithm, how can we tell? In a way we can propose that the natural laws we have discovered that seem to fully make reality deterministic is a kind of "algorithm" that generates reality. But can these laws (rules) still generate an aperiodic pattern?

	==> Consider if the algorithm to generate pseudo random numbers is an example of a finite algorithm that generates an aperiodic pattern?

If, for example, we imagine to use a pseudo random generator to choose a tile and a valid placement (of which there are a finite one if we have defined a path to travel at the edge of the current laid pattern), then it seems the resulting infinite aperiodic Penrose Tiling is in fact generated by a finite algorithm (the algorithm can be defined with a finite amount of information)?

Now, does this "mean" anything. To me it seems intriguing that we can fully define an infinite aperiodic pattern with a finite amount of information? How is that possible?
