2) Here seem to be a good place to read about building the llvm for windows using Visual Studio (http://llvm.org/docs/GettingStartedVS.html <http://llvm.org/docs/GettingStartedVS.html>)?

	==> Download llvm source
	==> Use CMake to generate Visual Studio solution files
	==> Open generated solution file in Visual Studio and build the LLVM for windows.

3) Here seem to be “An Example Using the LLVM Tool Chain” (http://llvm.org/docs/GettingStartedVS.html#id7 <http://llvm.org/docs/GettingStartedVS.html#id7>)

	==> Write hello.c program
	==> Call clang to compile into hello.bc (llvm internal byte code)

		> C:\..> clang -c hello.c -emit-llvm -o hello.bc 

	==> Run the byte code using the llvm

		> C:\..> lli hello.bc 

	==> Compile byte code to native windows obj-code

		> C:\..> llc -filetype=obj hello.bc 


	==> Link to exe-file using Visual Studio linker

		> C:\..> link hello.obj -defaultlib:libcmt 

	==> The resulting exe-file may now be run in Windows from command prompt 

		> C:\..> hello.exe
