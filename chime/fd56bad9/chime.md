Jag märker hos mig själv hur svårt jag har att njuta av att göra lustfyllda saker om jag ligger efter med det som jag måste göra och som är nödvändigt för att det praktiska i mitt liv skall fungera. Om jag till exempel städat och diskat så känns det med ens rätt att kunna unna sig att komponera den där nya låten på synten. Men om jag ligger efter med städningen så känns det inte alls lika meningsfullt att spela. På något sätt är det som om när jag gjort det nödvändiga så blir det lustfyllda meningsfullt?

1) Överväg att göra praktik av detta i Framtidens Religion - att se till att vilja göra det som är bra för en, alltså att bete sig så att man vill göra det nödvändiga.  
2) Det vore också bra om det fans praktiker genom vilka man också kan njuta medan man gör det nödvändiga. Om man både vill göra det nödvändiga (men tråkiga?) samt också finner flow eller njutning medan man gör dom så blir livet Djupt Rikare?

Så, vad kan vi tänka oss för aktiviteter som planterar både vilja att göra det Tråkiga Nödvändiga och göra det mindre tråkigt och i bästa fall njutningsfullt?

a) Praktiker för att komma igång. Ibland kan det räcka att bara komma igång så visar det sig inte vara så jobbigt. En sådan praktik kan vara att föreställa sig att man bara skall göra lite. Till exempel att bara göra det en liten stund (dammsuga en kvart) eller bara göra ett mindre arbetsmoment (bara tömma diskmaskinen).  
b) Praktiker för att gör det nödvändiga innan det kostar en något. Att skjuta upp och ha dåligt samvete eller på annat sätt känna sig tyngd av att det nödvändiga väntar på att bli gjort är en Djup Kostnad, livet blir mindre rikt. Och om man betalar sina räkningar för sent så kan det också kosta pengar i onödan. En praktik kan vara att göra en rutin som ser till att det nödvändiga blir gjort. En annan kan vara att att vänta med gott samvete med att göra det nödvändiga tills det absolut behöver göras, det vill säga oroa sig så lite som möjligt och minimera det nödvändiga.  
c) Praktiker för att göra det tråkiga nödvändiga så lätt att göra som möjligt.Städning kan bli mindre tråkigt om man möblerar sin lägenhet så den är enkel att städa och använder verktyg som gör städning enkel.  
d) Praktiker för att minimera mängden av det tråkiga nödvändiga. Man kan bestämma sig för att bilen nog klarar att inte städas och putsas hela tiden. Man kan använda autogiro för att betala räkningar. Man kan också äga mindre saker och teckna sig för färre avtal på tjänster varvid underhåll blir mindre och genererar mindre oro och krav på kontroll.  
e) Praktiker för att göra det nödvändiga på ett mer meningsfullt sätt. Man kan till exempel städa med batteridrivna verktyg (dammsugare) och ladda dem med pedaldriven generator. Då vet man att man städar med mindre miljöpåverkan och man har fått motion på köpet.
